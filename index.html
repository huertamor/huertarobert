Philosophy & Background

Teaching the craft of modern digital creation.

Digital media education thrives when technical precision and artistic intuition come together. My courses are designed to break down the complexities of modern web design into practical, empowering milestones.

Code as Creative Medium

Moving beyond template builders: teaching students to write semantic, clean HTML and modern CSS by hand to unlock total design control and accessibility.

Production-Ready Workflows

Fostering authentic industry standards through Git version control, GitHub Pages cloud hosting, browser developer tooling, and asset pipeline efficiency.

Visual Literacy & Intent

Bridging typography, hierarchy, color theory, and responsive layout systems so student projects are visually compelling across every screen size.

ART 10C Fall 2026 • Santa Monica College

Design for the Web: Principles, Coding & Interactivity

A foundational studio course exploring web design as both a communication system and a personal expressive medium. Students learn how to plan site architectures, author semantic HTML, create fluid responsive layouts with modern CSS, and deploy public projects using Git and GitHub Pages.

Digital Media Foundations: Imaging, Vector & Compositing

Introduction to digital imaging, vector illustration, and creative technology. Covers raster scanning workflows, pixel manipulation, digital collage, vector construction, and file organization protocols essential for creative industries.
